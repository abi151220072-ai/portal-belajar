⚡ Persiapan Firebase
Buat proyek Firebase gratis. Hanya perlu Firestore saja.
  1. 1
    Buka console.firebase.google.com → klik Tambah Proyek
  2. 2
    Setelah proyek jadi → klik ikon </> (Web) → daftarkan app web
  3. 3
    Menu kiri → Build → Firestore Database → Create database → pilih Production mode
  4. 4
    Di Firestore → tab Rules → ganti semua isinya dengan rules berikut lalu klik Publish:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{doc=**} { allow read: if true; allow write: if true; } } }
  5. 5
    Kembali ke Project Settings → Your apps → salin isi firebaseConfig
Buka Firebase
🔧 Tempel Konfigurasi Firebase
Salin seluruh isi { ... } dari bagian firebaseConfig di Firebase Console.
🔐 Buat Password Admin
Password ini hanya untuk kamu sebagai admin. Teman yang buka portal tidak akan diminta password apapun — mereka langsung lihat isi materi.
🎉 Setup Selesai!
