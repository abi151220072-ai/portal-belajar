Konfigurasi dilakukan sekali saja oleh admin

⚡ Persiapan Firebase
Buat proyek Firebase gratis — hanya butuh Firestore saja.
  1. 1
    Buka console.firebase.google.com → Tambah Proyek
  2. 2
    Klik ikon </> (Web) → daftarkan app web
  3. 3
    Menu kiri → Build → Firestore Database → Create database → Production mode
  4. 4
    Tab Rules di Firestore → ganti semua isinya dengan ini lalu klik Publish:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{doc=**} { allow read, write: if true; } } }
  5. 5
    Project Settings → Your apps → salin isi firebaseConfig
Buka Firebase
🔧 Konfigurasi Firebase
Salin seluruh isi { ... } dari firebaseConfig di Firebase Console.
🔐 Buat Password Admin
Password untuk kamu saja. Teman yang buka portal tidak perlu password — langsung lihat materi.
🎉 Setup Selesai!
Download file portal yang sudah dikonfigurasi untuk dibagikan ke teman atau diupload ke GitHub Pages.
